### 🌳 Raíz

**Tu árbol genealógico, en tu bolsillo.**

Aplicación Android **offline** para crear y guardar tu árbol genealógico.
Construida con **React + Vite + Capacitor**, con los datos almacenados
directamente en el dispositivo: sin conexión y sin depender de la nube.
